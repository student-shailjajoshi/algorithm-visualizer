06 / UNDERSTANDING THE ALGORITHM

How Binary Search works

Binary Search works on sorted data. Each comparison eliminates approximately half of the remaining search range.

01

Find the middle

Calculate MID using the current LOW and HIGH positions.

02

Compare

Compare the middle element with the target value.

03

Eliminate

Discard the half that cannot contain the target.

04

Repeat

Continue until the target is found or the range is empty.
