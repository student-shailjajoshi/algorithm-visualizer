UNDERSTAND THE ALGORITHM

How does Linear Search work?

Linear Search starts at the beginning of an array and examines each element sequentially. At every position, it compares the current element with the target. If both values match, the algorithm returns the index immediately. If they do not match, it moves to the next element. If the entire array is examined without finding a match, the algorithm returns -1. Because it does not require sorted data, Linear Search works with both sorted and unsorted arrays.

BEST CASE O(1) Target is at the first position
AVERAGE CASE O(n) May examine many elements
WORST CASE O(n) Target is last or not present
