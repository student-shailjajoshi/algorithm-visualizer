Choose a pivot, partition the array around it, and recursively sort the smaller sections. Watch how each pivot finds its final position.

WORST TIME O(n²)

STEP-BY-STEP

How it works

PSEUDOCODE

This implementation uses the Lomuto partition scheme, selecting the last element as the pivot.

01 quickSort(arr, low, high)
02 if low >= high: return
03 pivot = arr[high]
04 for j = low to high - 1
05 if arr[j] <= pivot: i++
06 swap(arr[i], arr[j])
07 place pivot at i + 1

UNDERSTAND THE ALGORITHM

What makes Quick Sort different?

Quick Sort follows the divide-and-conquer approach. It selects a pivot and partitions the current section into two groups. Elements smaller than or equal to the pivot are placed on its left, while larger elements remain on its right. Once partitioning is complete, the pivot reaches its final sorted position. The algorithm then recursively sorts the sections on either side.

BEST CASE O(n log n) Balanced partitions
AVERAGE CASE O(n log n) Reasonably balanced partitions
WORST CASE O(n²) Highly unbalanced partitions
SPACE O(log n) Average recursion stack
