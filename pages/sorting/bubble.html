BUBBLE SORT

01 for i = 0 to n - 1
02 swapped = false
03 for j = 0 to n - i - 2
04 if arr[j] > arr[j + 1]
05 swap(arr[j], arr[j + 1])
06 swapped = true
07 if swapped == false
08 break

THE BIG IDEA

Why is it called Bubble Sort?

Imagine bubbles rising to the surface of water. In Bubble Sort, larger values gradually move toward the end of the array with each pass. After one complete pass, the largest remaining value has reached its final position.

BEST CASE O(n) Already sorted, with early exit
AVERAGE CASE O(n²) Typical unsorted input
WORST CASE O(n²) Reverse-sorted input
SPACE O(1) Sorts in place
