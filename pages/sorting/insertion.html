01 / THE LOGIC

Follow the pseudocode

INSERTION SORT

The highlighted line shows exactly which instruction is being executed.

01 for i = 1 to n - 1
02 key = arr[i]
03 j = i - 1
04 while j >= 0 and arr[j] > key
05 arr[j + 1] = arr[j]
06 j = j - 1
07 arr[j + 1] = key
WHY THIS LINE?

The outer loop starts from index 1 because a single-element array is already considered sorted.

Let's understand Insertion Sort.

Insertion Sort maintains a sorted portion on the left. It takes the next element and inserts it into the correct position by shifting larger elements to the right.

THE BIG IDEA

Think of sorting playing cards.

Imagine holding cards in your hand. You pick up one new card at a time and insert it into the correct position among the cards you've already arranged. That's exactly how Insertion Sort works: the left portion stays sorted while each new element is inserted into it.

BEST CASE O(n) Already sorted input
AVERAGE CASE O(n²) Typical unsorted input
WORST CASE O(n²) Reverse-sorted input
SPACE O(1) Sorts in place
