Merge Sort.

Divide the array into smaller sections, sort each section recursively, and merge them back together in ascending order.

Merge Sort follows divide and conquer. It breaks the problem into smaller parts before combining the sorted results.

UNDERSTAND THE ALGORITHM

Divide. Conquer. Combine.

Merge Sort follows the divide-and-conquer approach. First, it divides the array into two halves recursively until individual elements remain. Since a single element is already sorted, the algorithm then starts merging these smaller sections. During each merge, it compares the front elements of two sorted sections and places the smaller element into the resulting array. This process continues until the entire array is sorted.

BEST CASE O(n log n) Consistent splitting and merging
AVERAGE CASE O(n log n) Divide and conquer
WORST CASE O(n log n) Predictable performance
AUXILIARY SPACE O(n) Temporary arrays for merging
