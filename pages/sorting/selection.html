Selection Sort.

Find the smallest element in the unsorted portion and place it at the beginning. Repeat until the entire array is sorted.

TIME COMPLEXITY O(n²)
SPACE COMPLEXITY O(1)

PSEUDOCODE

Follow the algorithm as it searches for the minimum element in the unsorted portion of the array.

01 for i = 0 to n - 2
02 minIndex = i
03 for j = i + 1 to n - 1
04 if arr[j] < arr[minIndex]
05 minIndex = j
06 swap(arr[i], arr[minIndex])

UNDERSTAND THE ALGORITHM

What makes Selection Sort different?

Selection Sort divides the array into two regions: a sorted portion on the left and an unsorted portion on the right. During each pass, it searches the entire unsorted portion for the smallest element. Once found, that element is swapped into the first position of the unsorted region. Unlike Bubble Sort, Selection Sort performs at most one swap per pass.

BEST CASE O(n²) Still scans the unsorted region
AVERAGE CASE O(n²) Quadratic comparisons
WORST CASE O(n²) Quadratic comparisons
SPACE O(1) Sorts in place
